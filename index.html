Five free productivity skills for AI coding agents

Agent Skills En is a small, MIT-licensed pack that teaches your coding agent repeatable working habits — install once, use in any project.

View on GitHub Browse on skills.sh

What you get

Commit message writer — consistent, readable commit messages your team will actually read.
Code review checklist — structured reviews that skip style nitpicks and focus on correctness and risk.
Tech writing proofread — a proofreading pass for technical docs that preserves your voice.
Meeting notes — turn raw notes into decisions, owners and follow-ups.
Deep research framework — a sourced, uncertainty-aware research workflow for agent tasks.

Install

npx skills add alapha888/agent-skills-en

Works with Claude Code, Codex and other agents that support the SKILL.md format. Free and open source (MIT). Also listed on skills.sh and AI Agents Listing.
